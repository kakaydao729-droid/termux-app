title: Overview
subtitle: Manage plants, store orders, and users with the Plant Store API
---

The Swagger Plant Store API is a sample REST API built on the OpenAPI 3.1 specification. Use it to add and search plants, track store orders and inventory, and handle user accounts and authentication.

The API reference is organized into three sections:

- **Plant endpoints**: Add, update, and look up plants by ID, and search them by status or tags.
- **Store endpoints**: Manage store orders and inventory. These endpoints require an `api_key`.
- **User endpoints**: Log users in and out and look up users by username.

All requests go to `https://api.plantstore.dev/v3`.
